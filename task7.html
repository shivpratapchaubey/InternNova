Reflection & Learning

During this HTML assignment, I learned the fundamentals of web development and how web pages are created using HTML5. I understood the basic structure of an HTML document, including the use of the head and body sections, headings, paragraphs, links, images, lists, tables, forms, and semantic tags. I also learned how to organize content in a meaningful and structured way. The most challenging topic for me was creating forms because there are many different input types and attributes to remember. However, with practice, I became more comfortable using them. The topic I enjoyed the most was working with semantic HTML because it made the webpage easier to organize and understand. I also liked adding images, tables, and hyperlinks to make the webpage more interactive. Learning HTML is an important first step in web development. It provides the foundation for creating websites and prepares me to learn CSS for designing webpages and JavaScript for adding interactivity. This assignment improved my confidence in building simple webpages from scratch.
