Understanding the CSS Box Model

Every HTML element can be considered as a box. The CSS Box Model consists of content, padding, border, and margin.

Box Model Properties

  • Width: Controls the width of an element.
  • Height: Controls the height of an element.
  • Margin: Creates space outside an element.
  • Padding: Creates space inside an element.
  • Border: Creates a boundary around an element.
  • Border Radius: Makes the corners rounded.
  • Box Shadow: Adds a shadow around an element.
